# Frequently asked questions

**Which files do I install?** Install both `/switch/Moader.nro` and `/kaihen/plugins/moader.nso` from the same release. [Installation guide](INSTALLATION.md#install-the-app-and-plugin)

**Why is my library empty?** Games appear after you [add a mod](USAGE.md#upload-your-first-mod).

**What happens after a reboot?** Your mods and settings stay on the SD card. Start [your setup method](INSTALLATION.md#start-the-backend-for-this-boot) again to use mods in games.

**Can I close Moader?** Yes. The resident plugin keeps the browser available while it is running. If the browser closes with the app, [check the plugin and connection](TROUBLESHOOTING.md#browser-or-app-connection).

**Why is Store gray?** The Store is disabled in this release. Download a mod ZIP from its publisher and use **Upload mod**.
