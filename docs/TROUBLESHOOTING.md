# Fix a problem

## Browser or app connection

- **Missing from hbmenu?** Check for `switch/Moader.nro` on SD.
- **Browser won't open?** Press **ZR → Start listener**. Open the displayed address on the same network.
- **Pairing failed?** Include all six digits, even leading zeros.

## Library and mods

- **Empty library?** [Upload a mod](USAGE.md#upload-your-first-mod).
- **Game unavailable?** [Choose your game copy](CARTRIDGES.md).
- **Mod has no effect?** Check the Title ID and [runtime connection](GETTING_STARTED.md#check-your-installation). Enable the mod and relaunch.

## A mod caused a software error

Disable the mod and restart the game.

## My ZIP is rejected

Check the [ZIP's size and folders](MOD_FILES.md#uploading-a-zip-instead).

<a name="the-setup-helper-rejects-my-input"></a>

## Backend setup failed or timed out

Save the error and report. A timed-out install may still be running.

## Reporting a problem

[Report the problem](https://github.com/H644b/Moader/issues) with your version and error. Hide your pairing code.
