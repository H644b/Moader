# Controls and settings

## Controller controls

| Button | Action |
| --- | --- |
| **L / R** | Browse games |
| **↑ / ↓** | Select a mod |
| **A** | Open or confirm |
| **B** | Go back |
| **ZR** | Show the browser address and pairing code |
| **ZL** | Show the debug log |
| **−** | Save a screenshot |
| **+** | Return to hbmenu |

## Settings

Press the **left stick** to open Settings. Under **General**, you can show game names, reduce motion or [choose a game copy](CARTRIDGES.md). **Connection** shows browser access. **Advanced** shows runtime status.

On the Switch, changes save automatically. In the browser, choose **Save settings** after editing preferences.
