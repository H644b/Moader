# Moader v0.1.2 — source-matched HEN refresh

v0.1.2 removes Moader's local pending-launch workaround from the custom kaiHEN source while retaining cooperative resident reload, cartridge checks, ZIP/library features and Linux/WSL/macOS setup routes.

## Upstream and component scope

Official kaiHEN **20261117.1** was checked. The existing qualified **20261114c** input and source base **`e897f991524590833b82fbe8d63a3c6775fb8101`** are retained: the newer command-23 interface conflicts with Moader's current reload ABI. No newer-upstream integration is claimed. The source change is the removal of Moader's local adjustment from its retained custom base. [Source disclosure](https://github.com/H644b/Moader/blob/main/docs/KAIHEN_CHANGES.md).

Use the matching app, resident and source-matched HEN/bootstrap components from this release. Copying an NRO or NSO does not update a running backend or its FS hooks. Follow the [installation guide](https://github.com/H644b/Moader/blob/main/docs/INSTALLATION.md) for a fresh per-boot setup and the [reload guide](https://github.com/H644b/Moader/blob/main/docs/PLUGIN_RELOAD.md) for subsequent compatible resident replacements.
