# Moader v0.2.0 — game carousel and community Store foundation

Moader now centers the selected game in a cover carousel. Open a game to manage its mods, then return to the same selection. The console app and paired browser use the revised library layout, and the new cartridge logo appears in hbmenu. Listener status, pairing and service controls are in Settings.

The native community Store can browse games, releases, galleries and independent publisher feeds. Its navigation button remains disabled in this release. The repository includes the [publisher template](https://github.com/H644b/moader-mod-repo-template), a [live example](https://h644b.github.io/moader-mod-repo-template/) and [interface walkthroughs](../../DESIGN.md).

The refreshed app and resident also fix installed covers that stayed blank when a Switch 2 game supplied only its compact icon. They request that icon first, then try the full-size icon for the same installed game and Edition. The paired browser accepts the returned JPEG or PNG, and the native debug report records cover failures by Title ID. [Fix in PR #23](https://github.com/H644b/Moader/pull/23)

The maintainer reported that the redesigned app worked on their console using an earlier NRO from commit [`cda6ecc`](https://github.com/H644b/Moader/commit/cda6ecc31acd90a8be179938f0062a515911c903), SHA-256 `bfb876a0de82a9dc1224b70a09fc8fd86e7ddb0a4d03c645234864161046eb57`. The refreshed v0.2.0 assets use the later source commit recorded in `release-manifest.json`; the protected v0.2.0 tag still points to the original release source. Host checks cover controller and touch input, installed icon fallback and decoding, mod management, settings, paired browser behavior, the Store gate and the publisher-feed reader. The exact refreshed app and resident have not been checked on a Switch 2. The backend components retain their separately recorded device and host validation scope.
