# Moader v0.2.0 — game carousel and community Store foundation

Moader now centers the selected game in a cover carousel. Open a game to manage its mods, then return to the same selection. The console app and paired browser use the revised library layout, and the new cartridge logo appears in hbmenu. Listener status, pairing and service controls are in Settings.

The native community Store can browse games, releases, galleries and independent publisher feeds. Its navigation button remains disabled in this release. The repository includes the [publisher template](https://github.com/H644b/moader-mod-repo-template), a [live example](https://h644b.github.io/moader-mod-repo-template/) and [interface walkthroughs](../../DESIGN.md).

Use the [installation guide](../INSTALLATION.md) for an existing backend or a fresh boot. Keep the app, resident and backend from the same release. The Seedsow route retains the source-qualified RO/HEN/bootstrap components from v0.1.3; use its [pinned GUI and preparation steps](../SEEDSOW.md), and do not replay a previous boot's native command.

## Verification

The maintainer reported that the redesigned app worked on their console using an earlier NRO from commit [`cda6ecc`](https://github.com/H644b/Moader/commit/cda6ecc31acd90a8be179938f0062a515911c903), SHA-256 `bfb876a0de82a9dc1224b70a09fc8fd86e7ddb0a4d03c645234864161046eb57`. The v0.2.0 binaries have new version labels and are rebuilt from the final tagged source; that earlier console check does not validate their exact bytes. Host checks cover controller and touch input, mod management, settings, paired browser behavior, the Store gate and the publisher-feed reader. The backend components retain their separately recorded device and host validation scope. [Detailed results](../VALIDATION.md)
