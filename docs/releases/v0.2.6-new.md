# v0.2.6-new experimental kaiHEN base

This prerelease ports Moader's matched RO/HEN/bootstrap changes onto the official [kaiHEN 20261117.1 release](https://github.com/ouncebrew/kaihen/releases/tag/20261117.1), SHA-256 `3f7ded0b360b2f0bf97f8e958c3bfe93a8d76dd8d43ce2e8f7d060e647ad0978`. Its source base is that release tag at `3695f364f9270686aa72cc39627bb1281752b2d3`; its SDK base is ounce-devkit 20261117. The complete regular archive remains intact except for Moader's patched `ro/main`, `hen/main` and `bootstrap.bin`, plus the Moader app and resident additions.

The new upstream uses HEN homebrew command 23 for its Loader root. This port keeps that command at 23, moves Moader's reload extensions to 24–28, and uses protocol 8 for the matched new app, resident, RO, HEN and bootstrap. Do not mix components from the older protocol-7 Moader kit with this one. The source patch replays exactly onto the upstream tag; the native cross-build, HEN/RO/bootstrap host tests, backend setup check, installer fixtures and Seedsow GUI auto-download fixture passed. The GUI's **Auto-Download Moader kaiHEN** button uses the kit's complete `bundles/kaiHEN-Moader-20261117.1.zip` and verifies the new matched components. It does not select an upstream Latest release at runtime.

The first kit stopped before opening its Seedsow listener with “Seedsow requires the complete official kaiHEN program set.” Its installer still expected the older OunceShell digest. The corrected kit checks the exact OunceShell size and SHA-256 from the pinned `20261117.1` archive. The archive-backed regression and complete offline Seedsow `--check` pass without console contact. Extract the corrected backend ZIP into a new directory so an older extracted helper is not reused.

This is **host-tested only**. There is no Seedsow installation or hold-R game-entry result for these new binaries. The prior clean-card Pokémon Z-A success applies to `v0.2.6-rc.2` on the older kaiHEN base, not to this prerelease.

For one controlled test, extract the new backend ZIP and follow the [Seedsow guide](../SEEDSOW.md) on a fresh Switch boot. After GUI success, close Seedsow, launch one native Switch 2 game normally without R for at least 20 seconds, close it fully, then hold R through the next launch. Save the complete GUI log and report the result. Do not rerun FS or HEN on a boot whose native result is failed or uncertain.
