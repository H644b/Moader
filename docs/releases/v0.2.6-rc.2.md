# v0.2.6-rc.2 first-launch capture candidate

An affected tester installed the previous rc.1 HEN with exact readback but still did not reach hbmenu after holding R through two game launches. Their archive ended at installation and contains no HEN trace after either launch, so the failing game-arm step is unknown.

This local candidate keeps the complete regular kaiHEN package and matched Moader RO/HEN/bootstrap pair. When no game policy is saved, HEN observes the first native Switch 2 game process and captures its signed policy even if the first R input sample was missed. That first game still launches normally; R is required to enter hbmenu on a later launch. The PM observation is bounded to once per quarter second and ignores Switch 1 titles. The full source patch replays, six HEN host suites pass, and the pinned AArch64 build succeeds.

The maintainer tested these exact HEN bytes through Seedsow Demo on a replacement SD card reported blank before setup. A fresh-boot installation verified HEN protocol 7/result 0, connected Moader resident/FS, restored FS cache and closed listener. The maintainer then launched Pokémon Z-A normally without R for at least 20 seconds, fully closed it, held R through a second launch, reached hbmenu and opened Moader with runtime and FS connected. Read-only SD FTP afterward found a 1,908-byte `META` game policy at `/kaihen/bin/game/main.npdm`. The file was not independently inspected before the first launch; the blank-card starting state is user-reported. An affected tester has not retested rc.2, so this is a successful controlled clean-card check, not a general fix claim.

For another controlled fresh-boot test, close Seedsow after the GUI's final success message. Launch one native Switch 2 game **without R** and leave it open for at least 20 seconds so the automatic capture has its full bounded window. Fully close it from HOME, then hold **R** from before selecting the same game through its second launch. Preserve the GUI log and report the game, docked or handheld state, whether sleep occurred, and whether `/kaihen/bin/game/main.npdm` exists after the first launch if the SD card can be inspected. Do not rerun FS or HEN on the same boot after a failed or uncertain attempt.
