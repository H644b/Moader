# Moader v0.1.3 — Seedsow backend kit

The refreshed v0.1.3 downloads include a prebuilt Seedsow Lullaby Demo or full-game backend kit. The backend ZIP contains the exact source-qualified RO, HEN and bootstrap binaries used in the recorded Demo installation, Moader's app and resident, the pinned GUI patch and its provisioning helper. The upstream Seedsow GUI and source are fetched from their reviewed revision during preparation. The kit also supports the SmileBASIC and experimental CivSwitch host profiles; their v0.1.3 native pair has host qualification, with no new device acceptance claimed for those routes.

The backend ZIP was refreshed after publication to fix the GUI's **Auto-Download Moader kaiHEN** button on a newly provisioned GUI. Its staging directory is now created and checked before the pinned archive is downloaded. Extract the refreshed backend ZIP into a new host folder and provision a new patched GUI folder with its helper; an older patched GUI folder may not match this kit's pinned patch. The RO/HEN/bootstrap, app and resident binary bytes are unchanged by this fix.

The kit now admits the full game's known program ID during held `process/qualify`, alongside the Demo ID. A reporter's full-game run reached that stage and stopped at the former Demo-only check. The pinned code preflight, FS and RO proof, process result check and no-replay ownership gates remain required. A complete Moader installation from the full game has not yet been recorded; provision a fresh GUI folder with this refreshed kit.

Choose a [setup method](../INSTALLATION.md#start-the-backend-for-this-boot). Seedsow users should follow the [Seedsow guide](../SEEDSOW.md), including its host SDK and pinned GUI preparation. Do not mix RO, HEN, bootstrap, app or resident files from different kits. After a full reboot, acquire a new qualified FS session; a saved run or installer command is not reusable.

## Validation and source

One Seedsow Demo installation on firmware 23.0.1 verified the exact RO/HEN/bootstrap component bytes in this kit and the previous app/resident build. Full-game identity acceptance has host tests; no full-game Moader installation is claimed. The v0.1.3 app and resident have new version labels and rebuilt bytes, with host validation only. Linux x86_64 previously passed the Seedsow source build and transport checks; WSL2 and a Linux/WSL live installation have no separate device record. CivSwitch has host-only integration coverage. [Detailed results](../VALIDATION.md)

The existing `v0.1.3` tag was published before these prebuilt assets. The release manifest identifies the later source commit used to build the ZIPs. GitHub's automatic **Source code** archives remain snapshots of the original tag; use the manifest's `sourceCommit` or the source included in the backend ZIP to inspect the exact packaged code.
