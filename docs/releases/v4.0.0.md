# Moader v4.0.0 — Setup and in-app updates

Five separate **Moader Setup** downloads provide prebuilt desktop apps for macOS, Linux and Windows with WSL2. Each self-contained app has the matching backend files and only its platform's pinned Node, uv and Electron runtimes. The smaller backend ZIP is for command-line use. The console app adds **Settings → Updates** for manual or optional automatic checks of the latest stable official release. It verifies both app and resident plugin downloads before installing them, can recover an interrupted update, and prompts you to reopen the app after the plugin restarts.

The v4.0.0 assets were refreshed after the tag to make the command-line backend smaller and provide separate prebuilt Setup apps. GitHub Actions packages the five OS and architecture downloads. The release manifest records the exact source commit for the refreshed ZIPs. The standalone Moader A route still needs an exact qualified local FS capture. The public kit does not contain that console-derived capture or its payload. The pinned kaiHEN RO, HEN, regular bootstrap and standalone bootstrap retain their recorded identities. The macOS desktop apps have ad hoc signatures and are not notarized; consult the [Setup guide](../SETUP_GUI.md#platform-and-release-limits) before using it on a quarantined download.

## Validation scope

PRs #40–#42 passed the repository's five CI checks. The in-app updater's host tests cover release parsing, file integrity, interrupted installation, recovery, restart handoff and input. The setup controller's host tests cover installer orchestration, SD readback, support export and failure handling. The themed desktop renderer was checked in 18 simulated layouts and states; a pre-release extracted Mac kit launched and completed host-only preparation for four backend methods. The exact v4.0.0 app, plugin, backend ZIP and five prebuilt Setup apps are built and hash-verified from the source commit in the manifest. A fresh Switch 2 installation, in-app update and the published desktop kit's Linux and Windows launchers have not been tested on hardware.
