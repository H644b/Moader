# Moader v4.0.0 — Setup and in-app updates

The backend kit now includes **Moader Setup**, a desktop app for guided host preparation, SD copying, connection checks and support export. It includes pinned Node, uv and Electron runtimes and launchers for macOS, Linux and Windows with WSL2. The console app adds **Settings → Updates** for manual or optional automatic checks of the latest stable official release. It verifies both app and resident plugin downloads before installing them, can recover an interrupted update, and prompts you to reopen the app after the plugin restarts.

## Validation scope

PRs #40–#42 passed the repository's five CI checks. The in-app updater's host tests cover release parsing, file integrity, interrupted installation, recovery, restart handoff and input. The setup controller's host tests cover installer orchestration, SD readback, support export and failure handling. The themed desktop renderer was checked in 18 simulated layouts and states; a pre-release extracted Mac kit launched and completed host-only preparation for four backend methods. The exact v4.0.0 app, plugin and backend ZIP are built and hash-verified from the source commit in the manifest. A fresh Switch 2 installation, in-app update and the published desktop kit's Linux and Windows launchers have not been tested on hardware.
