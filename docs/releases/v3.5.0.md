# Moader v3.5.0 — community Store

The Store is now available in the console app and paired browser. Browse the hosted community catalog, search releases and previews, filter to games found on the Switch, and install a verified package directly into the Library. New imports start disabled; enable them after checking the game and version. Removing a mod leaves its files recoverable and allows that release to be installed again.

## Validation scope

The PR host checks cover the Store catalog parser, controller navigation, paired HTTP flow, package size and SHA-256 validation, install and reinstall behavior, and game discovery fixtures. The host workflow also exercised installation and reinstallation through the live catalog in Chromium. Release preparation independently installed and reinstalled the live 242-byte Orchard palette package in an isolated host library, including mismatch rejection. The exact v3.5.0 app and resident are built and packaged from this source revision, with their digests in the release manifest. **Store installation and game discovery have not been tested on a physical Switch 2 with these v3.5.0 binaries.** The v3.0.0 standalone device result applies to its recorded app and resident pair; it is not a v3.5.0 device result. [Detailed validation](../VALIDATION.md#v350-community-store-release-scope).
