# CivSwitch (experimental)

The CivSwitch method uses Civilization VII on the Switch 2 and a Mac or Linux PC. Moader installation through this method still needs verification on a console. [CivSwitch test results](VALIDATION.md#experimental-civswitch-integration)

The v3.0.0 backend kit includes the CivSwitch computer notes. On an existing setup, Moader uses the same [app and required plugin](INSTALLATION.md#install-the-app-and-plugin) as the other methods. After opening the app, [verify the runtime connection](INSTALLATION.md#check-your-installation) before trying an in-game mod.
