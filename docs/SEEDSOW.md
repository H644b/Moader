# Seedsow Lullaby, PC-driven

Use this if you have an Apple Silicon Mac, an x86-64 Linux PC or Windows with x86-64 WSL2. You'll need the computer after each full reboot.

1. Download the [backend kit](https://github.com/H644b/Moader/releases/download/v3.0.0/Moader-backend-v3.0.0.zip).
2. In the v3.0.0 download, open `docs/SEEDSOW.md` for your edition. The Demo and the full game use different saves.
3. Open **Moader** from **hbmenu** and [check the connection](GETTING_STARTED.md#check-your-installation).

For later boots without a computer, see [Seedsow on-console (standalone)](SEEDSOW_STANDALONE.md).
