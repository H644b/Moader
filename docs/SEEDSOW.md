# Seedsow Lullaby, PC-driven

This method uses a computer each time the Switch starts from a full reboot.

## Requirements

- Seedsow Lullaby Demo or the full game. Each edition uses its own save.
- An Apple Silicon Mac, an x86-64 Linux PC or a Windows PC with x86-64 WSL2.
- The [v3.0.0 backend kit](https://github.com/H644b/Moader/releases/download/v3.0.0/Moader-backend-v3.0.0.zip), which includes the matching app and resident plugin.

## Installation

1. Extract the kit on your computer. In the published v3.0.0 download, open `docs/SEEDSOW.md` and use the instructions for your computer and edition.
2. After setup, confirm that [both required files](INSTALLATION.md#install-the-app-and-plugin) are on the SD card. Open **Moader** from **hbmenu**.
3. [Verify the runtime connection](INSTALLATION.md#check-your-installation) before enabling mods in a game.

[Seedsow on-console (standalone)](SEEDSOW_STANDALONE.md) uses a computer once for preparation.
