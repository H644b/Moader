# Interface illustrations

These images show synthetic sample libraries in the actual Moader interfaces. They explain the layout; they are not game screenshots or evidence that the example mods were installed.

- Native workbench and Settings: actual native software renderer, using the bundled Noto Sans font and canonical Moader mark. The sample connection uses an RFC 5737 documentation address.
- Browser workbench: Chromium viewing the actual local Moader web interface with synthetic metadata; loopback address only.
- No game assets, live pairing code, account information or private device captures are included.

The Moader mark is original project artwork. Noto Sans is distributed under its included SIL Open Font License.
