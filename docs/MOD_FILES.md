# Install a mod from the SD card

1. Find the game's 16-character Title ID. Use lowercase letters in the folder name.
2. Put each mod in its own folder. For a mod with a `romfs` folder, the path on SD looks like this.

   `/moader/library/<title-id>/<mod-name>/romfs/`

3. Choose **Refresh** in the browser and enable the mod.

## Uploading a ZIP instead?

Keep `romfs/` at the top of the ZIP or inside one enclosing folder. ZIP uploads can be up to **128 MiB**. [All supported files and limits](dev/USAGE.md#upload-your-first-mod).
