# Update the resident service

Use this if you run Moader's browser service while the app is closed.

## Use it

1. Finish any uploads. Copy `kaihen/plugins/moader.nso` from the matching [app ZIP](https://github.com/H644b/Moader/releases/download/v3.0.0/Moader-v3.0.0.zip) to the same folder on your SD card.
2. Open **Moader → Settings → Advanced → Reload Moader service**.
3. Keep Moader open until it reconnects. Refresh the browser page.

## Errors and recovery

If it says **Busy**, let the current task finish. If the result is unknown, keep Moader open and save the message. [Get help](TROUBLESHOOTING.md#reporting-a-problem).
