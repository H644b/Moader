# Getting started with Moader

<a name="app-only"></a>
<a name="copy-or-update-the-console-app"></a>

1. [Install Moader](INSTALLATION.md). The installation guide covers the downloads and the SD locations for both required files, `Moader.nro` and `moader.nso`.

<a name="play-with-mods"></a>
<a name="start-the-backend-for-this-boot"></a>

2. For in-game mods, [choose your setup method](INSTALLATION.md#first-time-setup). There is a separate [SmileBASIC guide](SMILEBASIC.md).

<a name="check-your-installation"></a>

3. [Verify the installation](INSTALLATION.md#check-your-installation), then [pair a browser and add your first mod](USAGE.md#connect-a-browser).

<a name="updating"></a>

Already have Moader? [Update the app and plugin together](INSTALLATION.md#updating).
